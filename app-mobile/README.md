# Lookout UnB

Aplicativo mobile desenvolvido com Expo e React Native para registrar ocorrências.

## Requisitos

- Node.js 20 ou superior.
- npm 11.20.
- Expo SDK 58 (`expo ~58.0.26`).

## Como executar

Na pasta `app-mobile`, instale as dependências e inicie o servidor:

```bash
npm install
npm start
```

No terminal do Expo, pressione `a` para Android, `i` para iOS ou `w` para web. Em um dispositivo móvel, também é possível escanear o QR code com o Expo Go.
